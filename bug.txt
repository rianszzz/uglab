  ### 2. Runtime Error NameError: name 'strength' is not defined (Cell Cetak Mean)                                       
                                                                                                                         
  • Gejala pada Gambar:                                                                                                  
      • Pada cell "Cetak nilai rata rata kekuatan semen pada dataset", muncul pesan error merah:                         
        Traceback (most recent call last)                                                                                
        ----> 3 strength                                                                                                 
        NameError: name 'strength' is not defined                                                                        
                                                                                                                         
  • Akar Masalah Teknis:                                                                                                 
      • Kode bawaan di notebook untuk cell ini sebenarnya sudah lengkap:                                                 
      print("Nilai mean dari kolom strength:", data['strength'].mean()) dan tidak memiliki placeholder <...>.            
      • Namun, AI menghasilkan jawaban terpisah berisi teks "strength".                                                  
      • Karena tidak ada <...> untuk digantikan, fallback lama menempelkan kata strength sebagai baris baru di akhir cell.
      • Saat fitur Run All dijalankan Colab, Python menganggap strength sebagai variabel mandiri yang belum              
      dideklarasikan, sehingga eksekusi notebook terhenti total (crash) di cell ini dan tidak melanjutkan ke cell-cell di
      bawahnya.

  ### 3. Soal Bagian Bawah (Cell 11 hingga 17) Tidak Terisi Sama Sekali (Masih <...>)

      • Cell Pearson correlation → masih # CODE HERE \n <...>                                                            
      • Cell Spearman rank correlation → masih # CODE HERE \n <...>

  • Akar Masalah Teknis:                                                                                                 
      1. Truncation Respon AI (Batas Output Web Mode):                                                                   
      Ketika 17 soal coding dikirim sekaligus dalam satu prompt besar, AI (Gemini Web) menghasilkan analisis CoT yang    
      sangat panjang terlebih dahulu. AI berhenti/memotong output setelah soal ke-10 atau ke-11, sehingga array JSON yang
      diterima hanya berisi 11 elemen (answers.length === 11). Soal ke-12 s/d 17 tidak memiliki pasangan jawaban.        
      2. Pergeseran Indeks Pemetaan Cell (Index Shifting):
      Karena pemetaan cell sebagian masih bergantung pada urutan array sequential (exerciseCells[i]), adanya cell yang   
      tidak memiliki <...> (seperti cell Cetak Mean) menyebabkan indeks jawaban berikutnya bergeser (off-by-one) dari    
      cell aslinya.
